# 실험 01: 캘리브레이션 기반 모음 인식 파이프라인

담당: 서은 / 상태: 동작 검증 완료(화자 2명), 파라미터 튜닝 진행 중

## 개요

사전학습 다화자 SVM 방식에서 **관람객별 즉석 캘리브레이션 방식**으로 전환한
음성 인식 파이프라인입니다. 관람객이 체험 시작 시 7모음(아·이·우·에·오·으·어)
× 3테이크의 짧은 발성을 제공하면, 그 자리에서 해당 화자 전용 SVM을 학습하여
실시간 인식에 사용합니다. 화자 간 음향 특성 차이(성도 길이 등)로 인한
범용 모델의 성능 저하 문제를 구조적으로 회피합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `calibrate.py` | 캘리브레이션 녹음: 7모음 × 3테이크(피치+거리 변화) + 오/우 거리 스위프 테이크. 무음/짧은 발성 자동 재시도 |
| `calib_train.py` | 화자별 SVM(RBF) 학습. LOTO(leave-one-take-out) 품질 체크, 마진 임계값(정답 프레임 마진 5퍼센타일) 자동 산출 |
| `calib_realtime.py` | 실시간 인식 스트림. 15ms 주기로 `{vowel, margin, f0, rms}` 출력 (향후 OSC 페이로드 원형) |
| `check_calib.py` | 캘리브레이션 wav 오프라인 재채점 (학습 정상 여부 확인) |
| `diag_live.py` | 라이브 발성을 캘리브레이션과 동일 경로로 채점 (실시간 파이프라인 vs 음향 요인 분리 진단) |
| `diag_compare.py` | 캘리브레이션 vs 라이브 MFCC 계수별 z-score 비교 (채널 변화 진단) |
| `feature_utils.py` | 공용 특징 추출 모듈 (MFCC, 무음 트리밍, 녹음 유틸) |

## 실행 환경

- Python 3.x / 패키지: `numpy`, `sounddevice`, `soundfile`, `scikit-learn`
- 마이크 필수. 노트북 내장 마이크는 비권장 (아래 실측 참고)

## 사용 순서

```
python calibrate.py        # 1. 화자 이름 입력 후 안내에 따라 녹음
python calib_train.py      # 2. 같은 이름 입력 -> LOTO 결과 확인 -> 모델 저장
python calib_realtime.py   # 3. 같은 이름 입력 -> 실시간 인식 테스트
```

- 생성물: `calib_wavs/<이름>/`(녹음), `calib_model_<이름>.pkl`(모델)
  — 둘 다 `.gitignore` 대상이라 커밋되지 않습니다
- LOTO 평균이 70%대 이하면 재녹음 권장

## 기술 요점

- **특징**: 프레임 단위 MFCC 13차 + 델타 13차 = 26차, 프레임별 RMS 정규화.
  학습·실시간의 정규화 방식을 반드시 일치시킴 (불일치 시 라이브 정확도 붕괴 사례 있음)
- **델타**: 중앙 차분 (t+1 − t−1)/2. 실시간에서는 판정을 1프레임(15ms)
  지연시켜 학습과 동일한 수식 유지
- **F0**: 간이 YIN(차이함수 + 누적평균정규화, numpy 벡터화). 60ms 창을 15ms마다 갱신
- **실시간 안정화 장치**:
  - 유성음 게이트 — F0 미검출 입력(박수 등 무성·충격음)은 판정 제외, MFCC 축적은 유지
  - 히스테리시스 — 새 라벨이 판정 창(150ms)의 60% 이상 + 연속 5프레임(75ms) 유지 시에만 표시 라벨 교체. 저신뢰 판정('?')은 라벨 교체 불가
  - 무음 시 표시 라벨 백지화

## 실측 결과 (내부 기준선)

> 동일 화자·동일 마이크 조건의 프레임 단위 LOTO 검증값입니다.
> 일반적인 인식 성능 지표가 아닌 내부 비교용 기준선입니다.

- 화자 1 (전용 마이크): LOTO 평균 **97.8%** / 노트북 내장 마이크: 75.4%
- 화자 2 (전용 마이크, 스위프 없는 구버전 프로토콜): LOTO 평균 86.1%

## 운영 조건 (전시 셋업 요청 사항)

**마이크 근거리(입 기준 약 한 뼘 이내) 발성을 전제로 안정 동작합니다.**
원거리 발성 시 저차 MFCC 계수 이동(마이크 거리에 따른 채널 변화)으로
'우' 인식이 불안정해짐을 z-score 진단으로 확인했습니다.
전시 설치 시 마이크 위치 고정 또는 발성 위치 안내가 필요합니다.
